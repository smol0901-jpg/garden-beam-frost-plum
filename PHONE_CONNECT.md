# Подключение телефона к `garden-beam-frost-plum` (одна Wi-Fi)

> Короткая памятка — держи её под рукой, пока поднимаешь доступ.

## 1. Что уже сделано установщиком

- Склонирован репозиторий `smol0901-jpg/garden-beam-frost-plum`
- Установлены npm-зависимости
- Создан `.env` в корне проекта:
  - `DATABASE_URL=` пуст -> БД будет **локальная (PGlite в файле)**
  - `VITE_AUTH_ENABLED=true` -> email/пароль вход **включён**
  - `BETTER_AUTH_SECRET=...` сгенерирован
  - `BETTER_AUTH_URL=http://<твой-IP>:8080`
- В Windows-файрвол добавлено правило для TCP `8080` (профиль Private)
- Запущен `npm run dev` в отдельном окне `garden-dev` (порт `0.0.0.0:8080`)

## 2. С телефона

1. Подключи телефон к **той же Wi-Fi**, к которой подключён ПК.
2. Открой в браузере телефона (Chrome / Safari / Яндекс) адрес:

   ```
   http://<IP-твоего-ПК>:8080
   ```

   IP показан в финальном экране установщика (обычно `192.168.x.x`).

3. Зайди на `/login` -> зарегистрируй первого пользователя (email + пароль).
   Этот аккаунт становится **"владельцем" БД**. Остальные тоже
   регистрируются через `/login`.

> **Не открывается?** Открой на ПК `cmd` и проверь:
> ```
> ipconfig
> ```
> Найди `IPv4-адрес` в активном адаптере Wi-Fi — это и есть твой адрес.
> Если телефон его пингует (приложение PingTools / Network Analyzer), но
> страница не грузится — это антивирус. Открой его настройки и разреши
> порт `8080` для `node.exe`.

## 3. Запуск/остановка

- **Запустить**: двойной клик по `run.bat` (или `python setup.py` в папке).
- **Остановить**: закрой окно `garden-dev` (Ctrl+C внутри).
- **Перезапустить**: закрой окно -> снова `run.bat`.

## 4. Что лежит в БД

По умолчанию (DATABASE_URL пуст) приложение поднимает **PGlite** — это
PostgreSQL, скомпилированный в WebAssembly. БД хранится **внутри процесса
Node**. После полной остановки и перезапуска `npm run dev` БД **пересоздаётся**
— это особенность "sandbox-режима" экспорта из Grok.

Если нужно **сохранять данные между перезапусками**, попроси — добавлю шаг
с реальным Postgres (Docker или облако Neon) и привяжу его через `DATABASE_URL`.

## 5. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `python не найден` | Поставь Python 3.10+ с python.org, отметь "Add to PATH" |
| `node не найден` | Поставь Node 20 LTS с nodejs.org |
| Порт 8080 занят | Закрой процесс на 8080 или смени PORT в `setup.py` и `package.json` |
| Файрвол отказал | Запусти `run.bat` от имени администратора |
| Телефон не видит ПК | Оба в одной Wi-Fi; отключи "изоляцию клиентов" в роутере (AP isolation) |
| 502/"Сервер не ответил" | Подожди — первый запуск ставит 600+ npm-пакетов, ~1–3 мин |
| Любая ошибка в окне `garden-dev` | Скопируй последние 30 строк и пришли мне |
